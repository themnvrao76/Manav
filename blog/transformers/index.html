00// SYSTEM OVERVIEW

One forward pass. Five big ideas.

At its core, a Transformer converts text into vectors, repeatedly mixes information between token positions, transforms features, and predicts what comes next. Click each stage to inspect its role and tensor shape.

⌁
Which Transformer? This walkthrough uses a decoder-only, causal language model as the default (GPT-style). You can switch to bidirectional encoder and encoder–decoder architectures in Chapter 07. The original 2017 Transformer was an encoder–decoder model.

Queries, keys & values

Every input vector is projected into three distinct representations. Queries ask what a position needs; keys describe what positions match; values carry the information to combine.

08// FAST AUTOREGRESSIVE INFERENCE

The key–value cache

Without caching, generation would repeatedly recompute past keys and values. A KV cache stores K/V for previous tokens, so each decoding step projects only the new token while attending to earlier cached positions.

DECODE_STEP_SIMULATOR

↗
The new query still attends over all available keys. Caching avoids repeated K/V projections for old tokens; it does not make attention over a growing context free. Production systems have additional memory and prefill/decode tradeoffs.
09// HIDDEN STATE → WORD DISTRIBUTION

Logits, softmax & sampling

A final projection maps the last token's hidden vector into one logit for each vocabulary entry. Softmax converts logits into probabilities. Temperature and top-k change how the next token gets selected.

10// HOW THE WEIGHTS ARE LEARNED

Next-token training & cross-entropy

During autoregressive training, a sequence is shifted by one position: each token predicts the next. The loss penalizes low probability assigned to the correct next token, and backpropagation updates the weights.

SHIFTED SUPERVISION
The same sequence supplies input and labels
L = −log p(target | preceding tokens)
Perplexity = exp(mean cross-entropy)

Production training sums or averages over many positions, examples, and batches. Padding and other tokens may be excluded from loss.
