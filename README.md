# manavbarot.com

Personal research portfolio and technical blog for **Manav Barot**.

## Stack

- GitHub Pages
- Jekyll
- HTML / CSS / JavaScript
- Markdown blog posts
- Custom domain: `manavbarot.com`

## Structure

- `index.html` — homepage
- `research/` — research directions
- `projects/` — selected projects
- `blog/` — Jekyll-powered blog index
- `about/` — profile
- `_posts/` — published Markdown articles
- `BLOGGING.md` — instructions for publishing a new post
- `assets/` — styles, JavaScript, images, favicon

## Publishing

GitHub Pages should publish from the `master` branch at the repository root.

The repository includes a `CNAME` file for `manavbarot.com`.
